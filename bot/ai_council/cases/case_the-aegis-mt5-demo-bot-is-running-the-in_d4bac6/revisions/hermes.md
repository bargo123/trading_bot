The calibrated model becomes a candidate baseline only if it shows statistically significant, out-of-sample-stable differences, and any resulting edit to promote.py's cost assumptions is then submitted for explicit operator authorization through the governed promotion process — no writes to intel/intelligent_champion.json, sealed holdouts, or any execution path occur during either phase.
