Revised proposal: Replay a **pre-specified** stratified sample of gated-out states through the identical demo-only exit/cost model, where strata are defined ex ante as the full symbol×session×direction grid with a minimum of 50 gated-out states per cell (no outcome-informed sampling), and "clusters" are exactly these cells—no post-hoc grouping. Because this is a multiplicity-rich search, admission requires Benjamini–Hochberg-corrected net-of-cost expectancy with a one-sided 95% lower bound ≥ +0.05R over ≥150 trades (n set by a power analysis targeting 80% detection of +0.05R at the corrected α, PF bootstrap CI excluding 1.0), stability across volatility-regime terciles, and confirmation on an untouched final temporal holdout (most recent 20% of bars) evaluated once after challenger selection is frozen. If no cell clears these gates, or if the cycle lacks the sample size the power analysis demands, the result is recorded as "insufficient evidence" rather than either confirmation or expansion—falsifiability is therefore bounded by data availability, which the registry will state explicitly. Every replay entry/exit must use only features observable at its decision timestamp, verified by an automated lookahead audit comparing feature timestamps against bar close times before any expectancy is computed. All replays—including failed clusters, rejects, and the insufficient-evidence case—are written to `ExperimentRegistry` (`bot/research/experiments.sqlite`) with sealed holdout hashes, so nothing is silently dropped; no live trading, YAML edits, or champion changes occur, and any surviving challenger still passes every `promote.py` gate.
