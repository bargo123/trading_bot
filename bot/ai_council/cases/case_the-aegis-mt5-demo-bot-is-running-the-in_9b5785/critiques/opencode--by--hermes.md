The 20%/90% bands, 15-minute timeframe, and 60-day window are three unpenalized degrees of freedom with no stated selection protocol — if they were picked after seeing holdout results, the "sealed" holdout is already burned, and nothing prevents iterative threshold-tuning against the same sealed set across repeated challenger attempts (no multiple-testing control or holdout rotation). The acceptance tests are statistically vacuous as written: "net expectancy improves" specifies no minimum effect size or significance test (e.g., bootstrap CI on per-trade net PnL), "no increase in maximum drawdown" allows no tolerance band despite drawdown being a high-variance estimator at n≈100, and "100 qualifying trades" never defines "qualifying." Missing validation: explicit point-in-time proof that the trailing percentile uses only decision-time data (lookahead risk), a paired same-entry comparison against the baseline so any delta is attributable to the filter rather than differing trade samples, and walk-forward or multi-regime coverage so one historical volatility regime can't manufacture the result. Finally, the proposal omits mandatory ExperimentRegistry logging (AGENTS.md rule 4), so even a pass would be an unrecorded experiment.
