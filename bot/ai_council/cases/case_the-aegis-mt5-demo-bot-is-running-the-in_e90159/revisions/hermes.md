Revised proposal: This audit is reframed as a strictly read-only screening-loss diagnostic, not a fill study — during one pre-registered cycle we log every rejected candidate state with its rejection reason, quote age, and contemporaneous book snapshot, then replay only states possessing a bounded-latency reference quote through the current champion's entry/exit logic under deliberately pessimistic costs (worst spread observed in a surrounding window plus a fixed stress multiplier), while states lacking any valid reference price are reported as unmeasurable rather than simulated. The single pre-registered primary endpoint replaces the arbitrary ≥200 target with a power calculation stating the minimum detectable effect up front: the difference in per-trade net EV between the replayed rejected population and admitted trades matched within the same session×symbol×time-of-day blocks, tested with a clustered bootstrap whose unit is the session-symbol-day to handle dependence and control the regime confound. Because means hide tails, we additionally report replayed CVaR-5%, execution-failure/unfillable rates, and per-session loss concentration, so the verdict concerns the whole distribution, not central tendency. A confidence interval spanning zero supports only the narrow claim "no evidence of materially screened edge under pessimistic costs"; a significant positive result changes nothing by itself. Any relaxation would proceed only as a separate governed proposal requiring explicit operator authorization and protected-config safety review, followed by live DEMO validation of the relaxed gate's real-time quote, spread, OMS, and fail-closed behavior via the designated broker-paper runner before promote.py evaluation against sealed holdouts. Both arms are logged in ExperimentRegistry and the champion remains untouched regardless of outcome.
