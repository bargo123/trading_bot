AEGIS is a five-layer quant research system — ingestion (MT5 read-only), a 71-module offline research layer (25+ algo catalogue, 40+ intel meta-filters, analogue store, thesis fire/sizing/economics), governed champion promotion with bootstrap stress and sealed holdouts, a paper-only runner, and an optimizer cycle — all anchored to a net-negative base strategy (EURUSD M1, 1-pip TP / 30-pip SL, 95.7% win rate, PF 0.27) that the intelligent layer is designed to filter into profitability. No challenger has yet cleared the full promotion gauntlet; `intelligent_champion.json` remains unpopulated. The most promising untested lever is the 25+ algorithm catalogue in `session_algos.py` (Hale, Volman, Chan, Fabris, Steidl, etc.), which is registered but has never been systematically evaluated through the governed walk-forward → sealed-holdout → bootstrap promotion path that GEN1–GEN6 apply to the CORE firehose meta-filters; a concrete experiment would be to run the full runner generation pipeline against each catalogue algo on the same EURUSD M5/M15 datasets and compare their OOS expectancy, payoff asymmetry, and `wins_erased_by_average_loss` metric against the CORE baseline — if any algo achieves OOS expectancy > 0 and PF > 1 with fewer than 4 wins erased per average loss, it would be the first candidate worthy of governed promotion review.
